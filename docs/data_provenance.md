# Data Provenance

## Source dataset

- GEO accession: GSE69683
- Platform: GPL570
- Tissue: whole blood
- Assay: Affymetrix microarray

## Required provenance record

For every source file, record:

- filename;
- source URL or API endpoint;
- accession and version;
- download date;
- checksum;
- whether values were already normalized;
- transformations applied by this repository;
- script and software version used.

## Redistribution

Confirm GEO and platform-annotation terms before including source files. Prefer scripts and documented accessions when redistribution is unnecessary.
