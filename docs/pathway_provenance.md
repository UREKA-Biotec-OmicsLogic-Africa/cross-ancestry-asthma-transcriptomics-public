# Pathway Provenance

The ten curated asthma pathways must be versioned and traceable.

For each pathway, record:

- pathway name;
- gene-symbol namespace;
- full gene list;
- expected and observed gene counts;
- source references;
- curator;
- verification date;
- inclusion rationale;
- exclusions or replacements;
- changes between releases.

The canonical pathway definitions should be loaded from `data/gene_sets/`, not copied into notebooks.
