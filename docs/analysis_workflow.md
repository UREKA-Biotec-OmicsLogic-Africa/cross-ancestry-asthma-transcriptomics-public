# Analysis Workflow

## Planned stages

1. Retrieve GEO source data.
2. Validate the sample manifest.
3. Construct the 24-sample probe-expression matrix.
4. Perform quality-control checks.
5. Run PCA and, if retained, pre-specified t-SNE.
6. Perform genome-wide ancestry comparison.
7. Perform genome-wide gender comparison.
8. Map probes to genes using documented rules.
9. Fit gender-adjusted curated-gene models.
10. Run GSEA and ssGSEA.
11. Run exploratory co-expression analyses.
12. Generate manuscript and supplementary outputs.
13. Validate manifests, checksums, dimensions, and reported counts.

Add a workflow diagram and exact input-output mapping after implementation.
