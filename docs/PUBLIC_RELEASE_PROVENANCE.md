# Public release provenance

This repository is a sanitised reproducibility snapshot derived from an
internally version-controlled private development repository.

The public repository intentionally excludes manuscript drafts, editorial
working files, private correspondence, superseded manuscript versions and
other private publication-development materials.

The authoritative numerical analysis supporting the associated studies is
represented by:

`notebooks/shared/Cross_Ancestry_Asthma_Transcriptomics_PUBLICATION_MASTER_EXECUTED_v1.ipynb`

The omission of manuscript files does not alter the analytical data,
software, figures, tables or reproducibility resources supporting the
studies.
