# Cross-Ancestry Asthma Transcriptomics

This staging repository supports two manuscripts from one authoritative executed analysis of GSE69683.

## Publication scope

This repository is the internal master development and reproducibility
repository supporting two companion severe-asthma whole-blood transcriptomics
manuscripts derived from the same version-controlled cohort and authoritative
executed analysis.

### Manuscript 1

Manuscript 1 focuses on gene-level differential expression, including
genome-wide probe-level analysis, curated asthma genes, ACKR1/Duffy-related
interpretation, and the reciprocal sex contrast as an internal validation
analysis.

### Manuscript 2

Manuscript 2 focuses on systems-level analysis, including pre-ranked GSEA,
ssGSEA pathway scores, curated-gene co-expression architecture, node
centrality, and descriptive subgroup networks.

The manuscripts share cohort and analytical provenance while their
manuscript-facing results have been deliberately partitioned to minimise
redundant reporting.
